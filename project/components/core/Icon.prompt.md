A Lucide icon, for function only: a microphone, a close, a password eye, sign out. The site imports each icon per component from `@lucide/angular`; never register the whole set.

Never decoration, never a section illustration, and never the arrow in a call to action: that is the typed `→`.

```jsx
<Icon name="mic-off" size={18} />
<Icon name="x" size={16} />
```
