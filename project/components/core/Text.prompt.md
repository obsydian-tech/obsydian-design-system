Type in one of the system's roles. Every role is General Sans; headlines are 500 and tight, reading text is 400 at -0.01em, and only `eyebrow`, `label` and `action` are uppercase.

```jsx
<Text as="h2" role="section" balance>What we deliver</Text>
<Text role="lede" tone="dim">Four practice areas. One team.</Text>
<span style={textStyle('label', 'var(--bone-low)')}>Partner enquiries</span>
<Button arrow>Start a project</Button>   // the → comes from <Arrow/>
```
