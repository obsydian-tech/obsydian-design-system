# Obsydian Design System

Interactive design system reference for Obsydian Technologies — colors, typography, components, and brand guidelines.

**Live site:** https://obsydian-tech.github.io/obsydian-design-system/

## Local preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Source

The standalone bundle was exported from the Obsydian design system and is served as a single self-contained page (`index.html`).
